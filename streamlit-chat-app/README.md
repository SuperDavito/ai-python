# Streamlit Chat Application

This project is a simple chat application built using Streamlit that connects to the OpenAI API. Users can input prompts and receive responses generated by the AI.

## Project Structure

```
streamlit-chat-app
├── src
│   ├── app.py          # Main entry point for the Streamlit application
│   └── utils
│       └── openai_client.py  # Handles OpenAI API interactions
├── requirements.txt    # Lists project dependencies
└── README.md           # Project documentation
```

## Setup Instructions

1. **Clone the repository:**
   ```
   git clone <repository-url>
   cd streamlit-chat-app
   ```

2. **Create a virtual environment (optional but recommended):**
   ```
   python -m venv venv
   source venv/bin/activate  # On Windows use `venv\Scripts\activate`
   ```

3. **Install the required dependencies:**
   ```
   pip install -r requirements.txt
   ```

4. **Set up OpenAI API key:**
   Make sure to set your OpenAI API key in your environment variables. You can do this by adding the following line to your `.bashrc` or `.bash_profile` (Linux/Mac) or using the command prompt (Windows):
   ```
   export OPENAI_API_KEY='your-api-key'  # Linux/Mac
   set OPENAI_API_KEY='your-api-key'      # Windows
   ```

## Usage

To run the application, execute the following command in your terminal:
```
streamlit run src/app.py
```

Open your web browser and navigate to `http://localhost:8501` to start using the chat application.

## Features

- User-friendly interface for inputting chat prompts.
- Real-time responses from the OpenAI API.
- Simple and clean design for an optimal user experience.
